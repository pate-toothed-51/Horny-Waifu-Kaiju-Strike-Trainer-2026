## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Horny Waifu: Kaiju Strike**. A Windows trainer and quality-of-life overlay for the Steam version of Horny Waifu: Kaiju Strike. It provides convenient controls for the game's auto-battle and 2x battle-speed functions, displays session information, and assists with team and formation management without attempting to modify server-side currencies, summons, progression, PvP results, or guild data.

**Target Audience:** Players who want convenient keyboard shortcuts, faster routine campaign battles, and clearer team-management information while using the Windows Steam version.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

The game uses menu-based navigation rather than an open-world movement system. Use the mouse or normal interface controls to move between the campaign, heroine roster, summoning, equipment, gallery, guild, arena, and tournament screens. The trainer does not add free-roam movement.

### Tools & Inventory

Heroine progression uses levels, equipment, runes, star ascension, gold, gems, and heroine shards. Use the in-game inventory and character screens to manage these items. The trainer can display selected progression information but does not create, remove, or alter account-bound resources.

### World & Environment

The story takes place on Terion, a world threatened by the Darkness and the Kaiju it creates. Progress through chapter-based campaign stages, replay completed missions for rewards, recruit new heroines, and access additional activities such as guild raids, arena matches, and tournaments.

### Combat & Weapons

Combat is turn-based and built around a squad of five heroines positioned in Front, Middle, and Rear rows. Build energy during encounters to activate Ultimate abilities, manage team composition and synergy, and defeat enemies before demanding bosses enrage. The trainer provides shortcuts for the built-in auto-battle and 2x speed options.
